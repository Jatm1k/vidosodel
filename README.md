# Vidosodel

Студия для производства длинных YouTube-видео (16:9) из сценария:

```
сценарий → озвучка (Lumean) → тайминги → сцены → промпты (LLM) → картинки (FastGen) → видео с анимацией → метаданные и обложки
```

Каждый шаг работает отдельно и в связке: можно сделать только озвучку, загрузить свою озвучку
или SRT и сгенерировать только картинки, заменить любую картинку своей, собрать видео из готового.

## Запуск

**Windows:** дважды щёлкните `start.bat`.
**Linux/macOS:** `./start.sh` (нужны Python 3.11+ и ffmpeg из пакетного менеджера).

При первом запуске скрипт сам:

1. найдёт Python 3.11+ или установит Python 3.12 для текущего пользователя;
2. создаст `.venv` и поставит зависимости (повторно — только после их изменения);
3. скачает ffmpeg в `tools/ffmpeg`, если его нет в системе;
4. соберёт интерфейс, если исходники менялись (Node.js при необходимости скачается в `tools/node`);
5. запустит сервер и откроет `http://127.0.0.1:8765` в браузере.

Ключи Lumean и FastGen задаются в интерфейсе (**Настройки → Ключи API**) или в файле `.env`
(шаблон — `.env.example`). Кнопка «Проверить» у ключа FastGen подставит лимиты вашего тарифа.

## Как пользоваться

1. **Канал** — пресет под YouTube-канал: голос для каждого языка (шаблоны Lumean, подбор голоса
   с прослушиванием прямо в приложении), стиль и референсы картинок, длительность сцен, движение
   камеры и переходы, субтитры, уникализация, параметры метаданных.
2. **Проект** — одно видео. Вставьте сценарий, выберите языки и режим картинок
   (*одни на все языки* — экономия кредитов, или *свои для каждого языка*), и нажмите
   «Создать и запустить». Проект может переопределить любую настройку канала.
3. **Языковая версия** проходит пять этапов — у каждого своя вкладка:
   - **Сценарий** — редактирование, автоперевод с основного языка, бесплатная оценка цены озвучки;
   - **Озвучка** — генерация в Lumean, загрузка своего аудио (с распознаванием таймингов) или только SRT;
   - **Раскадровка** — разбивка на сцены (по смыслу через LLM или по предложениям), визуальная
     библия проекта, промпты, картинки; монтажная лента и правка каждой сцены (промпт, своя картинка,
     разделить/объединить, движение и переход);
   - **Видео** — быстрое превью фрагмента и финальный рендер;
   - **Публикация** — варианты названия, описание с главами, теги, обложки 1280×720.
4. **«Запустить конвейер»** продолжает с места остановки: готовые шаги пропускаются.

Очередь задач переживает перезапуск: незавершённые задачи продолжатся (озвучка подхватит уже
оплаченный заказ Lumean, генерация картинок доделает только недостающие).

## Что делает видео пригодным для YouTube

- H.264 High, yuv420p, BT.709, GOP 2 с, `faststart`; 1080p / 1440p / 4K, 24–60 к/с.
- Звук: двухпроходная нормализация EBU R128 к −14 LUFS, AAC 256 кбит/с, 48 кГц.
- Движение камеры с субпиксельной точностью (без дрожания `zoompan`), 9 типов движения и 9 переходов.
- Уникализация каждого рендера: цветокоррекция, плёночное зерно, виньетка, микрозум, порядок
  эффектов, неслышимая эквализация звука, очистка метаданных.
- Субтитры: вшитые (обводка, подсветка слов, плашка) и всегда отдельный `.srt` для загрузки.
- Автоматическое удаление видимого водяного знака у моделей, которые его ставят.
- Главы в описании по абзацам сценария.

## Лимиты сервисов

- **FastGen**: планировщик держит число одновременных генераций, почасовой бюджет кредитов на картинки
  и почасовой бюджет токенов LLM (скользящее окно + сверка со счётчиком сервера по всему ключу, так что
  траты других людей с тем же ключом учитываются). Если лимит занят, задачи ждут, а не падают.
  Сколько картинок в час даёт выбранная модель — видно в настройках канала; текущий расход —
  внизу боковой панели.
- **Lumean**: оплата по факту; перед озвучкой текст проверяется бесплатным предрасчётом
  (цена, фрагменты, которые заблокирует контентная политика).

## Архитектура

```
backend/app/
  main.py, __main__.py     FastAPI-приложение, раздача UI и медиа, точка входа
  config.py, db.py         настройки процесса, SQLite (WAL) + аддитивные миграции
  models.py                Channel → Project → Track (язык) → Scene; Job; FastgenUsage
  settings_schema.py       настройки конвейера: умолчания ← канал ← проект
  services/                клиенты Lumean и FastGen, лимитер FastGen
  pipeline/                тайминги, предложения, разбивка на сцены, выравнивание языков, LLM-задачи
  render/                  движение, переходы, «лук», субтитры, параллельный рендер, ffmpeg
  jobs/                    постоянная очередь задач и обработчики шагов, события для UI
  api/                     REST-эндпоинты и поток событий (SSE)
frontend/                  Vue 3 + PrimeVue 4 + Tailwind 4 (собранная версия в frontend/dist)
scripts/bootstrap.py       установка и запуск
```

Рендер: каждый кадр — чистая функция плана, поэтому диапазоны кадров рендерятся параллельно в
нескольких процессах (OpenCV → raw-поток → ffmpeg) и склеиваются без перекодирования.
Аппаратные энкодеры (NVENC / Quick Sync / AMF) определяются автоматически.

## Обновления

Программа обновляется с GitHub: при каждом запуске `start.bat` проверяет новую версию, показывает,
что изменилось, и предлагает обновиться. Во время работы о новой версии сообщит значок в боковой
панели. Ваши данные, ключи и настройки при обновлении не затрагиваются. История изменений —
в [CHANGELOG.md](CHANGELOG.md).

Чтобы обновления работали, программу нужно установить через git:

```
git clone https://github.com/Jatm1k/vidosodel.git
```

## Разработка

Ветки, формат коммитов, журнал изменений и выпуск версий — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

```
cd backend && ../.venv/Scripts/python -m app      # API на :8765
cd frontend && npm install && npm run dev         # UI на :5173 с прокси к API
```

Данные: `data/` (база `vidosodel.db`, медиа, свои шрифты для субтитров в `data/fonts`).
